# covertrackpad.com

The website for **Cover Screen Trackpad** — an app that turns the cover screen of
a Samsung foldable into a rear trackpad, so a finger on the back of the phone
drives a pointer on the main display.

Static HTML, no build step, no dependencies. Served by GitHub Pages at
[covertrackpad.com](https://covertrackpad.com).

| File | Purpose |
| --- | --- |
| `index.html` | Landing page and FAQ |
| `setup.html` | Setup guide, including Shizuku |
| `privacy.html` | Privacy policy — required by Google Play at a public URL |
| `style.css` | Shared styling for all three pages |
| `CNAME` | Custom domain. **Do not delete** — removing it clears the domain. |
